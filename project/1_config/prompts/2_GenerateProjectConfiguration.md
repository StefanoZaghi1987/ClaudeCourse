# Prompt: Generate Claude Desktop Project Files for Training Course

Please generate three comprehensive artifacts for a Claude Desktop project focused on organizing and delivering a professional training course on Claude Desktop and Claude for Code platforms.

## Context

I am a senior trainer and consultant with 20+ years of experience in Generative and Agentic AI technologies. I need to create a Claude Desktop project to help me organize and deliver a comprehensive training course for my colleagues at my company.

### Course Overview

**Target Audience:** Heterogeneous group of colleagues with different roles, skills, and operational capabilities within my company.

**Primary Objectives:**
- Share general concepts and guidelines regarding logic and use of tools based on generative AI technologies
- Illustrate the main features and usage methods of Claude Desktop and Claude for Code
- Clarify the potential and limitations of these tools
- Share general best practices for using Claude Desktop and Claude for Code
- Share best practices for specific areas and well-defined workflows
- Provide practical examples of tasks that can be performed with Claude's help
- Provide "Spec-driven development" guidelines for developing prototype solutions with structured workflows

**Course Requirements:**
- Cover all aspects of Claude Desktop and Claude for Code platforms in broad spectrum
- Address main topics useful in everyday operational work
- Provide vertical and in-depth training starting from scratch to advanced knowledge
- Address both established topics and recently introduced advanced features
- Timeline: To be defined
- Approach: 30% theoretical, 70% practical

**Delivery Method:**
- Remote training via Microsoft Teams
- Each session recorded and transcribed
- Post-session reports prepared and shared with recordings

**Required Tools:**
- Claude Desktop
- Notepad++ (https://notepad-plus-plus.org/downloads/)

**Optional Tools:**
- Visual Studio Code (https://code.visualstudio.com/download)
- GitHub Desktop (https://desktop.github.com/download/)

### Pre-Course Participant Submissions

Each participant has been asked to share:

1. **General Expectations**
   - General expectations regarding the course
   - Topics they would like to address
   - Knowledge they would like to acquire

2. **Current Use of Claude**
   - Activities where Claude has been used effectively
   - Activities where Claude was unable to provide effective support
   - Doubts and concerns regarding current usage
   - Activities where they would like to introduce Claude as a support tool

3. **Practical Test**
   - One test or prototype solution idea of medium-high complexity
   - Feasible in approximately 2 days of work
   - Has actual value for the participant
   - Could be: a task not yet successfully completed with Claude, a task where Claude could be introduced, a repetitive activity to optimize, or a prototype tool for a specific workflow

### Project Support Needs

This Claude project should help me:
- Define all course topics precisely
- Define course timeline and operational aspects
- Improve my knowledge and skills for optimal course preparation
- Organize the course in the best possible way
- Draft additional documentation for various lessons
- Prepare and complete exercises for course sessions
- Analyze documentation shared by each participant and cover their needs

## TASK

Implementa il MathMCP Server eseguendo il piano di sviluppo task-by-task, usando

---

## CONTESTO

Il progetto MathMCP è un MCP Server scritto in TypeScript che espone 8 tool matematici
(4 base + 4 avanzati) tramite stdio transport, costruito sull'MCP SDK ufficiale.

**Documenti di riferimento obbligatori:**

- **Specifica funzionale e architetturale:**
  `specs/math-mcp-server-design.md`
  Contiene: inventario completo dei tool, formato di output atteso (successo ed errore),
  matrice dei casi limite con messaggi di errore esatti, architettura del progetto
  (struttura file, tipo ToolDefinition, flusso di registrazione), configurazione
  TypeScript e dipendenze npm.

- **Piano di sviluppo:**
  `plans/math-mcp-server-plan.md`
  Contiene: 7 task sequenziali con step granulari in formato checkbox, file map,
  istruzioni di build/test per ogni step, comandi di commit Git.

**Approccio di sviluppo:**

Il piano adotta un workflow TDD per ogni task (eccetto scaffolding e registry):
scrivere prima i test → verificarne il fallimento → implementare → verificarne il
successo → committare. Questo ciclo è vincolante: non saltare la fase di verifica
del fallimento.

**Stack tecnologico:** TypeScript (ES2022, Node16, strict mode), `@modelcontextprotocol/sdk`,
`zod`, `vitest`.

- Leggi integralmente la specifica e il piano prima di iniziare qualsiasi implementazione.
- Esegui i task nell'ordine definito dal piano (Task 1 → Task 7), senza saltarne nessuno.

- Aggiorna lo stato dei checkbox nel piano dopo il completamento di ogni step.
- Al termine di ogni task, verifica che build e test siano verdi prima di procedere
  al task successivo.
- Non alterare la struttura dei file definita nella File Map del piano.
